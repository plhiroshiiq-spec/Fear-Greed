# EXT のデータ源の選定記録(P5)

対象: SPEC.md 9.2章。

> 寄り前の外部環境を1つだけ。既定はSOX指数の前日比%。データ源は無料のものをP5で選定し、
> 取得失敗時は枠ごと非表示にする(誤った値は絶対に出さない)。

- **結論: engine(GitHub Actions)が取得し、`data/ext.json` に前日比%だけを置く。**
- **ソース: stooq を第1候補、Yahoo Finance(非公式)を予備。どちらも無料・APIキー不要。**
- 判断日: 2026-09-18 / 運用費: **0円**

---

## 1. なぜアプリから直接叩かないか

SUMI DECK から直接ソースを叩くと、次が全部アプリ側の問題になる。

- ソースの仕様変更・遮断でアプリが壊れる(更新にストア配信が要る)
- 端末ごとに取得が走り、ソースに余計な負荷をかける
- 検証ロジックを Kotlin にもう1本持つことになる

engine 側に寄せれば、**アプリは既に読んでいる raw URL をもう1本読むだけ**で済む。
ソースが変わっても engine の更新だけで直る。fg.json と同じ経路なので、
キャッシュ・stale の扱いも使い回せる。

## 2. 保存するもの

**前日比%だけ。** 指数の水準そのものは保存しない。SPEC.md 8章の「保存するのはスコアと
派生統計のみ」と同じ方針で、再配布の問題を避ける。`tools/check_no_raw_data.py` が
`ext.json` のキーを機械的に検査する。

```json
{
  "schema": 1,
  "generated_at": "2026-09-18T06:41:12+09:00",
  "ext": {
    "key": "sox", "name_ja": "SOX指数", "source": "stooq",
    "as_of": "2026-09-17", "change_pct": -1.50, "stale": false
  }
}
```

## 3. ソースの選定

| ソース | URL | 費用 | APIキー | 位置づけ |
|---|---|---|---|---|
| stooq | `https://stooq.com/q/d/l/?s=^sox&i=d` | 無料 | 不要 | 第1候補。CSVで形が単純 |
| Yahoo Finance | `https://query1.finance.yahoo.com/v8/finance/chart/^SOX` | 無料 | 不要 | 予備。非公式で遮断されることがある |

**⚠️ この選定は実データで未検証。** P5 の作業環境は外向き通信がポリシーで制限されており、
どちらのホストにも到達できなかった(P4 と同じ制約。docs/price_source.md 参照)。

**なぜそれでも実装したか**: GitHub Actions のランナーからは外に出られることが P1 で実証済み
(CNN の取得に成功している)。したがって**初回のワークフロー実行が実地の検証になる**。
かつ EXT の失敗は設計上どこにも波及しない。

- ソースは順に試し、片方が落ちてももう片方で拾う
- 検証(下記)に1つでも外れたら**採用しない**
- すべて失敗しても**既存の ext.json を上書きせず**、`stale:true` だけ立てる
- **終了コードは常に0**。EXT は任意機能なので `fg.json` の更新を巻き込まない

なお SOX は**指数**なので、P4 で問題にした株式分割の調整は関係しない。
指数の構成銘柄入れ替えは指数値の計算側で吸収される。

## 4. 妥当性検証(1つでも外れたら採用しない)

| 条件 | 理由 |
|---|---|
| `as_of` が未来でない | 時刻ずれや形式取り違えの検出 |
| `as_of` が7日以内 | 連休を考慮しつつ、止まったソースを弾く |
| `|change_pct| <= 30` | 指数で1日30%は起きない。桁の取り違えを弾く |
| 2行以上の終値が取れている | 前日比が計算できない状態で数値を作らない |

## 5. 表示側の扱い

9.2章は「取得失敗時は枠ごと非表示」としているが、6.1章・6.4章は「完全非表示は手動オフの時だけ」
「取得失敗で枠を消すことを禁止」としており、**両者が正面から衝突する**。
経緯と現在の実装は `docs/spec_diff.md` D16 に記録した。**発注者の判断待ち**。

どちらを選んでも「誤った値は絶対に出さない」(9.2章)は守る。`stale` の EXT の数値は出さない。

## 6. 別の指標に変える場合

`fg/ext.py` の `KEY` / `NAME_JA` と、各ソース関数のシンボル(`^sox`)を変えるだけでよい。
検証のしきい値は指数を前提にしているので、個別株や為替に変える場合は見直すこと。
